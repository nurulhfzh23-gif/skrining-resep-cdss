# skrining-resep-cdss
Sistem CDSS berbasis web untuk otomatisasi skrining resep (Administratif, Farmasetik, Klinis &amp; Interaksi Obat) sesuai standar Permenkes. Menggunakan data resep nyata. Dilengkapi dashboard analitik interaktif, filter status, ekspor CSV, dan generator SBAR untuk meningkatkan keselamatan pasien (patient safety) di fasilitas kesehatan.
